# Anate Studio — інструкція з підтримки сайту

Це статична версія сайту anatestudio.net. Оригінальний динамічний проєкт (Node.js/Express) лежить окремо і не змінюється — ця версія створена спеціально для хостингу, який не підтримує Node.js.

## Структура проєкту

- `gameList.mjs` — **єдине** місце, де описані ігри (назва, фото, посилання на Steam/Xbox/тощо, скріншоти). Редагувати ігри — тільки тут.
- `locales/en.json`, `locales/ua.json` — тексти сайту (переклади) для кожної мови.
- `views/` — EJS-шаблони (HTML-розмітка сторінок).
- `public/css`, `public/images` — стилі та картинки.
- `app.mjs` — сервер для **локального перегляду під час редагування** (не для продакшену).
- `build.mjs` — скрипт, який генерує готовий статичний сайт у папку `dist/`.
- `dist/` — готовий статичний сайт, саме його заливаємо на хостинг.

## Як внести зміни (повний цикл)

### 1. Встановити залежності (тільки один раз, або якщо якщо папка `node_modules` відсутня)
```
npm install
```

### 2. Редагувати контент
- Нова гра / зміна посилань / скріншотів → `gameList.mjs`
- Зміна текстів → `locales/en.json` та `locales/ua.json`
- Нові картинки → `public/images/`

### 3. Перевірити локально перед збіркою
```
npm run dev
```
Відкрити `http://localhost:3000/ua` (або `/en`), перевірити, що все виглядає правильно.

### 4. Зібрати статичну версію
```
node build.mjs
```
Це оновить папку `dist/` — саме її вміст (а не весь проєкт) потрібно заливати на хостинг.

### 5. Залити на хостинг (bitteserver)

1. Запакувати папку `dist/` у `.zip`-архів (усередині архіву мають бути одразу файли, а не сама папка `dist`)
2. Зайти в ISPmanager → **"Менеджер файлів"**
3. Перейти в `www` → `anatestudio.net` (**саме в цю підпапку**, не в `www` напряму!)
4. Видалити всі файли/папки, що там є (`css`, `en`, `images`, `locales`, `ua`, `index.html`)
5. Завантажити новий `.zip` (кнопка "Додати")
6. Розпакувати його прямо тут (кнопка "Archive" → Extract)
7. Видалити сам `.zip`-файл після розпакування

**Якщо сайт показує помилку 403 "Forbidden"** — це майже завжди означає, що в якоїсь папки неправильні права доступу після розпакування (треба `755`, а буває виставляється `644`, без права "заходити" в папку). Виправлення:
1. Виділити проблемну папку (або всі файли/папки в `anatestudio.net`)
2. Кнопка **"..."** або **⚙️** → **"Атрибути"**
3. Встановити права `755`, за потреби — рекурсивно (для всіх файлів усередині)

⚠️ **Дуже важливо:** працювати тільки всередині `www/anatestudio.net/`. Ніколи не видаляти нічого на кореневому рівні акаунту (`email`, `www`, `.cagefs`, `etc`, `logs` тощо) — там системні файли й поштова скринька, і видалення може зламати хостинг та пошту.

### 6. Залити зміни на GitHub

```
git add .
git commit -m "короткий опис зміни"
git push
```

## Якщо потрібно скачати проєкт на новий комп'ютер

```
git clone <адреса репозиторію>
cd anatestudio26-static
npm install
```
Після цього можна користуватись `npm run dev` для перегляду й редагування, і `node build.mjs` для збірки.
